fermat
=============================

[English](./README.md)

进程内查找与小集合用的 C++ 容器：Swiss table 哈希、有序 vector、b-tree、HAT-trie、
自适应基数树（ART）、Roaring bitmap。构建系统是
[kmcmake](https://github.com/koomx/kmcmake)。

**不在本仓库：** bit/整数编解码（PFor、ZFP 等）应放独立编码库。这里的 Roaring 是
**整数集合**，不是 bitstream codec。

给 Agent：先读 [`fermat/skills.h`](fermat/skills.h) 和
[`docs/CONTAINERS.md`](docs/CONTAINERS.md)，不要扫全库源码。

## 🛠️ Build

本项目通过 CMake presets 构建。三条依赖线（不自动探测）：

- 空：`default` / `test` / `test-bm` / `all` — 系统 `find_package`
- CPM：`cpm` / `cpm-test` / `cpm-test-bm` / `cpm-all` — `KMCMAKE_USE_CPM=ON`
- vcpkg：`vcpkg` / `vcpkg-test` / `vcpkg-test-bm` / `vcpkg-all` — 需 `VCPKG_ROOT`

无后缀为 Ninja（`build/`）；`-make` 为 Unix Makefiles（`build-make/`）。
`default` / `default-make` 不写 cache 变量。无范围后缀的 `cpm` / `vcpkg` 只编库。

测试依赖 GTest。多数 bench 依赖 Google Benchmark；`roaring_all_benchmark` 自带 main。

### 0. 准备环境

- Linux (Ubuntu 20.04+ / CentOS 7+ 推荐) / macOS / Windows（推荐 MSVC + Ninja）
- CMake >= 3.31
- GCC >= 9.4 / Clang >= 12 / MSVC（VS 2022+）
- 默认 preset 需要 PATH 中有 `ninja`
- 可选：使用 `--preset=vcpkg*` 时设置 `VCPKG_ROOT`

### 1. 配置项目（可选，vcpkg / CPM）

- vcpkg：设置 `VCPKG_ROOT`；manifest 模式在工程根放 `vcpkg.json`
- CPM：改 `cmake/*_cpm.cmake`，用 `--preset=cpm*`
- 系统包：`--preset=default` 或 `--preset=test`，在 `cmake/*_deps.cmake` 里 `find_package`

### 2. 编译项目

在项目根目录执行：

```bash
# Ninja → build/
cmake --preset=default
cmake --build build -j$(nproc)

# Unix Makefiles → build-make/
cmake --preset=default-make
cmake --build build-make -j$(nproc)

# 示例
# cmake --preset=test
# cmake --preset=cpm-test
# cmake --preset=vcpkg-all
```

***注意***

- 项目根目录 `CMakePresets.json` 定义上述预设。

### 3. 运行测试(可选)

```shell
ctest --test-dir build
# 若使用 -make preset：
ctest --test-dir build-make
```

Roaring 测例名为 `roaring_<case>`。Roaring demo 在 `examples/`，不在 tests。

### 4. 基准（可选）

```bash
./build/benchmark/art/art_all_benchmark
./build/benchmark/roaring/roaring_all_benchmark --help
```

Roaring 真实数据集在 `refs/CRoaring-master/benchmarks/realdata`。
